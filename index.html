Prozorro Sale AWS Auth Controller Chart Repository

This is the Helm chart repository for the Prozorro Sale aws-auth-controller application.
Support MapAccount, MapUser, MapRole CRDs

helm repo add aws-auth-prozorro https://redacid.github.io/aws-auth-controller/
helm repo update
helm search repo aws-auth-prozorro

see https://github.com/redacid/aws-auth-controller/charts for more details
